# 솔버 캐스케이드 전역 중앙 우선 순서 변경 리포트 (2026-08-12)

## 변경 목적

기존 4단 순서는 `Cedar 중앙 → Cedar 전체 → SEP 중앙 → SEP 전체`였다.
그러나 상·하단에는 광학 왜곡, 지평선 광해와 장애물이 포함되어 패턴 오류를
일으킨다는 현장 관찰이 있다. 중앙에 솔빙 가능한 별이 충분하다면 검출기
종류보다 중앙 영역을 우선하고, 전체 프레임은 최악의 경우에만 써야 한다.

## 변경 내용

캐스케이드를 다음과 같이 변경했다.

1. Cedar 중앙 정사각
2. SEP 중앙 정사각
3. Cedar 전체
4. SEP 전체

Cedar 중앙 솔빙 동안 SEP 검출을 병렬 실행하는 구조는 유지한다. Cedar
중앙이 실패하면 준비된 SEP 중앙 좌표를 즉시 시도하며, 두 중앙 경로가 모두
실패한 뒤에만 전체 좌표를 허용한다. `solver_center_first=false`의 기존
롤백 경로는 변경하지 않았다.

## 검증

- 순서 회귀 테스트 3개 추가
  - SEP 중앙 성공 시 Cedar 전체와 SEP 전체가 호출되지 않음
  - SEP 중앙 실패 시 Cedar 전체가 다음으로 호출되고, 성공하면 SEP 전체가
    호출되지 않음
  - 두 경로가 모두 실패하면 SEP 전체가 마지막으로 호출됨
- 관련 테스트: **39개 통과**
- `compileall` 및 `git diff --check` 통과
- 실제 서비스 재시작 후 `pifinder.service=active`
- 변경 전 라이브 결과: `cedar_ff_center`(새 이름 `cedar_center`),
  Cedar 65→57→43, 36매칭,
  RMSE 12.9″, solve 34.4ms
- 명칭 변경 후 재시작 검증: `/api/solution`에 `solve_path=cedar_center`가
  실제 발행됨. Cedar 59→53→41, 30매칭, RMSE 11.0″. 중앙 성공으로
  `cedar_full`/`sep_full`은 실행되지 않음

라이브 하늘에서는 1단 중앙 경로가 성공했으므로 전체 프레임 단계가 실행되지
않았다. 이는 새 정책의 정상적인 조기 종료다. 후속 실패 순서는 인위적으로
하늘 조건을 훼손하지 않고 단위 테스트의 호출 기록으로 검증했다.

## 판정

캐스케이드는 이제 전역 중앙 우선 정책과 일치한다. 경로 이름도 솔빙 영역
기준으로 정리하여 `cedar_center` 또는 `sep_center` 성공이 정상 우선
결과이며, `cedar_full`과 `sep_full`은 중앙 두 경로가 모두 실패한 경우에만
허용되는 구제 결과로 해석한다. 기존 `cedar_ff_center`/`cedar_ff`/`sep`는
각각 `cedar_center`/`cedar_full`/`sep_full`로 변경했다.
