# 광각 타일 LiveCam 운영 가이드

최종 업데이트: 2026-08-20

이 문서는 현재 구현된 광각 타일 **표시·선택·영속 저장** 기능의 운영 기준이다.
타일을 실제로 plate solve 하거나 제외 타일을 솔버에 적용하는 단계는 아직 구현되지
않았다. 따라서 이 기능은 현재 LiveCam 진단/설정 준비용이며 기존 솔빙 경로를 바꾸지
않는다.

상세 장기 설계는 [광각 렌즈 다중 구역 솔빙 및 왜곡 보정 설계](mf_wide_angle_solver_design_ko.md)를,
후속 구현 순서는 [단계별 구현 계획](mf_wide_angle_solver_implementation_plan_ko.md)을 참고한다.

## 1. 표시 조건과 켜기

- Lens 메뉴에서 선택한 렌즈 또는 수동 초점거리가 **10.0mm 이하**일 때만 LiveCam
  도구에 `Wide tiles`와 `Edit exclusions`가 나타난다.
- `Wide tiles`는 기본 Off다. 체크하면 오버레이를 표시한다.
- `Edit exclusions`를 켠 상태에서 타일 이름 또는 해당 논리 셀을 누르면 제외/복원이
  즉시 전환되고 설정 파일에 저장된다.
- 12/16/25mm 렌즈, 또는 수동 초점거리 10.1mm 이상에서는 도구가 숨겨진다.

## 2. 타일 계획 규칙

현재 `mf_wide_tiles.py`는 렌즈 FOV가 아닌 원본 pixel 크기를 기준으로 한다.

- 실제 솔버 후보 타일은 항상 **512×512 이상 원본 정사각**이다. 현재 최소값은
  512px이며 작은 프레임을 512px로 확대하지 않는다.
- 각 축은 중앙 `C` 타일이 영상 중심에 오도록 홀수 개의 시작점으로 구성한다.
- 프레임 가장자리까지 덮기 위해 인접 실제 타일은 기본 20%를 목표로 중첩한다.
  프레임 크기 때문에 실제 중첩률은 더 커질 수 있다.
- 짧은 축이 512px보다 작은 프레임은 이 계획을 만들지 않고 안전하게 타일을 표시하지
  않는다.

예를 들어 1080×1920 LiveCam 프레임은 512px 타일 기준으로 3열×5행, 총 15개가
될 수 있다. 이 수는 렌즈의 FOV가 아니라 프레임 pixel 크기와 중첩 정책에 따라
정해진다.

## 3. 오버레이 읽는 법

LiveCam에는 실제 겹치는 정사각을 그대로 클릭하게 하지 않는다. 겹친 영역에서는
클릭 대상이 모호해지기 때문이다.

| 표시 | 의미 |
| --- | --- |
| 타일 이름 | 선택용 논리 셀 중앙의 tile ID. 이름 위를 눌러도 해당 셀이 선택된다. |
| 가는 점선 영역 | 둘 이상의 실제 512×512 타일이 겹치는 영역 |
| 굵은 점선 정사각 | 실제 중앙 `C` 타일의 512×512 footprint |
| 반투명 강조 footprint | 제외로 선택한 실제 512×512 타일. 논리 셀 크기가 아니라 실제 영향을 표시한다. |

색은 Web 테마 변수를 사용한다. Red Night 테마에서는 오버레이도 붉은 계열로
표시된다. 논리 셀의 실선 격자는 표시하지 않으며, 이는 실제 tile 경계와 혼동되는
것을 막기 위한 의도된 동작이다.

## 4. 제외 설정의 저장 범위

제외 tile ID는 `config.json`의 `mf_wide_excluded_tiles_by_optics`에 저장된다.
저장 키에는 카메라 타입, 렌즈 키 또는 수동 초점거리 값이 포함되므로 다른 optical
train으로 전파되지 않는다. 재부팅 뒤에도 같은 optical train이면 복원된다.

현재 API는 다음과 같다.

| API | 동작 |
| --- | --- |
| `GET /api/camera/wide-tiles` | 현재 광학 조합의 타일, 실제 crop footprint, overlap, 제외 상태 반환 |
| `POST /api/camera/wide-tiles` | `excluded_tile_ids` 목록을 유효한 현재 tile ID로 검증 후 영속 저장 |

## 5. 현재 제한과 후속 단계

- 화면은 현재 LiveCam source frame 기준이다. 왜곡 보정/rectified canvas는 아직
  연결되지 않았다.
- 제외 설정은 저장/표시만 하며 현재 production solver에는 적용되지 않는다.
- 광각 타일 솔버를 연결할 때는 원본 tile 해상도에서 검출하고 tetra3에 실제 입력
  크기와 tile별 FOV를 전달해야 한다. 512×512 production 경로로 단순 업스케일해서는
  안 된다.
- 다각형 기구 간섭 마스크와 tile별 solve/consensus/Integrator 좌표 발행은 후속
  검증 단계에서 추가한다.
